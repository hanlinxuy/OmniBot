## Bounded verifier follow-up

The verifier now additionally accepts only three specifically observed Python `zipfile` script shapes, comparing parsed syntax to a fixed template bound to the exact fixture path and `file_1.txt`; it does not run the model's command. It requires a successful terminal tool and exit code, the expected structured stdout, and the exact final answer. Tests reject a different ZIP or entry, a failed tool, a constant print, and duplicate qualifying calls; existing ACP tests reject multiple or missing owners. This is deliberately not a general shell or Python verifier, so other valid commands can still be reported as unverified.
