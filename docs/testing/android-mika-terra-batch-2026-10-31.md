## 可比起点的批量观察开销

新增无内容计时字段，记录 Android 动作前观察、原生派发、宿主稳定等待，以及 Python 动作后带截图观察、后备等待；批量 receipt 单独记录 XML 刷新、受守卫派发和本地等待。`dispatch` 合计包含动作及动作后观察，不能再与其子项相加。模型耗时来自现有 RunLog。
